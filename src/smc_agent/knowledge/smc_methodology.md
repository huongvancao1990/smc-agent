# Phương pháp SMC + Setup 1:3 RR (theo infographic gốc)

## Khái niệm cốt lõi

| Khái niệm | Tiếng Anh | Định nghĩa |
|-----------|-----------|-----------|
| **BOS** | Break of Structure | Giá phá vỡ đỉnh/đáy quan trọng → xác nhận tiếp diễn xu hướng. |
| **CHoCH** | Change of Character | Giá phá vỡ cấu trúc hiện tại → khả năng đảo chiều xu hướng. |
| **IDM** | Internal Liquidity | Thanh khoản bên trong, giá quét đỉnh/đáy nhỏ trước khi đi tiếp. |
| **FVG** | Fair Value Gap | Khoảng trống giá trị công bằng — giá thường quay lại lấp đầy. |
| **Order Block** | — | Vùng có khối lệnh lớn từ dấu chân Smart Money. |

## Quy trình phân tích 5 bước

1. **Xác định xu hướng chính (BOS).**
2. **Tìm IDM bị quét.**
3. **Xác định Order Block + FVG.**
4. **Chờ tín hiệu xác nhận (Price Action).**
5. **Vào lệnh với tỉ lệ 1:3 RR.**

## Setup MUA (BUY) — 1:3 RR

1. Giá phá BOS tăng.
2. Quét thanh khoản IDM (đáy nhỏ).
3. Hồi về Order Block / FVG.
4. Xuất hiện tín hiệu tăng (price action confirmation).
5. Vào lệnh BUY với SL dưới Order Block, TP = 3R.

## Setup BÁN (SELL) — 1:3 RR

1. Giá phá BOS giảm.
2. Quét thanh khoản IDM (đỉnh nhỏ).
3. Hồi lên Order Block / FVG.
4. Xuất hiện tín hiệu giảm.
5. Vào lệnh SELL với SL trên Order Block, TP = 3R.

## Vùng mua/bán lý tưởng

- ✓ Quét thanh khoản IDM (đỉnh/đáy nhỏ).
- ✓ Hồi về Order Block + FVG (overlap cho confluence).
- ✓ Xuất hiện tín hiệu xác nhận (engulfing, pin bar, BOS nội bộ).
- ✓ Rủi ro thấp - Lợi nhuận cao (1:3 RR tối thiểu).

## Lưu ý quan trọng

- Luôn đi theo xu hướng chính.
- Kiên nhẫn chờ giá về đúng vùng POI (Order Block / FVG).
- Quản lý vốn và rủi ro chặt chẽ — không bao giờ phá SL.
